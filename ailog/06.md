.onTapGesture って何？












.onTapGesture は、画面上の部品がタップされたときに処理を実行するためのSwiftUIの機能です。
Text("タップしてね")
    .onTapGesture {
        print("タップされました")
    }
この場合、文字をタップすると { } の中が実行されます。
たとえば、タップするたびに色を変えるなら次のように書けます。
struct ContentView: View {
    @State private var isRed = false

    var body: some View {
        Rectangle()
            .fill(isRed ? Color.red : Color.blue)
            .frame(width: 200, height: 200)
            .onTapGesture {
                isRed.toggle()
            }
    }
}
isRed.toggle() は、値を次のように反転します。
false → true
true → false
そのため、タップするたびに青と赤が切り替わります。
複数回タップを判定することもできます。
Text("ダブルタップしてね")
    .onTapGesture(count: 2) {
        print("ダブルタップされました")
    }
ただし、一般的なボタン操作には .onTapGesture よりも Button を使う方が適切です。
Button("保存") {
    print("保存しました")
}
.onTapGesture は、画像やカード、図形など、本来ボタンではないViewにタップ処理を追加したいときによく使います。










Swiftのインクリメントってなんだっけ？












Swiftでは、インクリメントとは「変数の値を1増やすこと」です。
例えば、count が 5 の場合、
count += 1
と書くと、
count = 6
になります。
昔の言語との違い
CやJavaでは、
count++;
のように ++ が使えますが、
Swiftでは ++ は廃止されています。
そのため、Swiftでは必ず
count += 1
と書きます。
デクリメント（1減らす）
1減らしたい場合は、
count -= 1
です。
例
var score = 10

score += 1
print(score)   // 11

score -= 1
print(score)   // 10
toggle()との違い
Bool型（true / false）は数値ではないので、インクリメントはできません。
var isOn = false

isOn.toggle()   // false → true
isOn.toggle()   // true → false
数値を1増やす → += 1
数値を1減らす → -= 1
真偽値を反転する → .toggle()
この3つはSwiftでよく使う基本操作です。










Swiftの++は他に使ったりするからとかそういう理由？












そう。それも理由の一つだよ。
Swiftから ++ と -- が廃止された主な理由は、コードを分かりやすくして、ミスを減らすためなんだ。
例えばCやJavaでは、
i++;
++i;
この2つはどちらも1増えるけど、式の中では意味が変わる。
int a = 5;
int b = a++;
// a = 6
// b = 5

int c = 5;
int d = ++c;
// c = 6
// d = 6
++が前に付くか後ろに付くかで挙動が違うから、初心者だけでなく慣れた人でも読み間違えることがある。
さらにこんなコードも書けてしまう。
array[i++] = value;
一見すると分かりにくいけど、
array[i] に代入する
その後 i を1増やす
という処理になっている。
Swiftでは、
array[i] = value
i += 1
と2行に分けて書くので、何をしているかが一目で分かる。
だからSwiftでは、
+= や -= は「値を変更する文」
++ や -- のように「値を返しながら変更する演算子」は廃止
という設計になっている。
Appleは「短く書けること」よりも「誰が読んでも分かりやすいこと」を重視しているんだ。
実際にSwiftの設計方針では、コードは書く回数より読む回数の方が圧倒的に多いという考え方が大切にされているので、その思想が ++ の廃止にも表れている。

これのminimumDurationって何？




展開







minimumDuration は、何秒以上押し続けたら「長押し成功」と判定するかを指定する値です。
この場合は「1秒間のロングプレス」なので、
.onLongPressGesture(
    minimumDuration: 1.0
) {
    isPressed = true
}
と書きます。
つまり、
minimumDuration: 1.0
は「1秒以上押し続けたら、後ろの処理を実行する」という意味です。
完成形はこうです。
.onLongPressGesture(
    minimumDuration: 1.0
) {
    isPressed = true

    DispatchQueue.main.asyncAfter(
        deadline: .now() + 1
    ) {
        isPressed = false
    }
}
minimumDuration: 2.0 なら2秒、minimumDuration: 0.5 なら0.5秒です。










長押しを検知する.??? のやつはなんて書くの？












長押しを検知するSwiftUIのモディファイアは
.onLongPressGesture
です。
例えば一番シンプルなのは、
Circle()
    .onLongPressGesture {
        print("長押しされた")
    }
長押し時間を指定する場合は、
Circle()
    .onLongPressGesture(
        minimumDuration: 1.0
    ) {
        print("1秒以上長押しされた")
    }
さらに、「押している途中」も検知したい場合は pressing を使います。
Circle()
    .onLongPressGesture(
        minimumDuration: 1.0,
        pressing: { isPressing in
            print(isPressing) // 押している間 true、離すと false
        }
    ) {
        print("長押し成功")
    }
つまり、覚えておくとよいものは次の2つです。
タップを検知 → .onTapGesture
長押しを検知 → .onLongPressGesture
どちらも「Viewにジェスチャーを追加するモディファイア」です。
