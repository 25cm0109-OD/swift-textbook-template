# フォトマップアプリ 実装教科書

## このアプリで作るもの

写真を選び、現在地と一緒に保存するアプリを作ります。

保存した記録は、

* 地図上にピンとして表示される
* 一覧画面で確認できる
* ピンを押すと詳細を見られる
* 写真・タイトル・メモ・位置情報をSwiftDataに保存できる

という構成です。

# Step 2：保存するデータの形を作る

次に、「写真1枚分の記録」を表すモデルを作ります。

`ContentView.swift` の `struct ContentView` より上に書いてください。

```swift
@Model
class PhotoRecord {
    var title: String
    var memo: String
    var latitude: Double
    var longitude: Double
    var imageData: Data?
    var createdAt: Date

    init(
        title: String,
        memo: String = "",
        latitude: Double,
        longitude: Double,
        imageData: Data? = nil
    ) {
        self.title = title
        self.memo = memo
        self.latitude = latitude
        self.longitude = longitude
        self.imageData = imageData
        self.createdAt = .now
    }
}
```

## このモデルが持っている情報

```swift
var title: String
```

記録のタイトルです。

例：

```swift
"渋谷で食べたラーメン"
```

```swift
var memo: String
```

補足メモです。

例：

```swift
"友達と行った。醤油ラーメンが美味しかった"
```

```swift
var latitude: Double
var longitude: Double
```

地図上の場所を表す緯度・経度です。

```swift
var imageData: Data?
```

選択した写真を保存するためのデータです。

`UIImage` のまま保存するのではなく、`Data` に変換してSwiftDataへ保存します。

```swift
var createdAt: Date
```

記録を作った日時です。

# Step 3：地図用の座標を作る

`PhotoRecord` のクラス内、`init` の下にこれを追加します。

```swift
var coordinate: CLLocationCoordinate2D {
    CLLocationCoordinate2D(
        latitude: latitude,
        longitude: longitude
    )
}
```

これで、保存した緯度・経度をMapKitで使える形に変換できます。

地図はこの形の座標を使います。

```swift
CLLocationCoordinate2D(
    latitude: 35.6812,
    longitude: 139.7671
)
```

# Step 4：保存した写真を表示できるようにする

同じく `PhotoRecord` の中に追加します。

```swift
var uiImage: UIImage? {
    guard let data = imageData else {
        return nil
    }

    return UIImage(data: data)
}
```

保存しているのは `Data` ですが、画面に画像を表示するには `UIImage` が必要です。

流れはこうです。

```text
写真ライブラリ
↓
Dataとして取得
↓
SwiftDataに保存
↓
DataをUIImageに変換
↓
SwiftUIのImageで表示
```

ここまでで、データモデルは完成です。

これは、

```text

```

# Step 6：位置情報を取得するクラスを作る

続いて現在地を取得するためのクラスを作ります。

`PhotoRecord` の下あたりに追加してください。

```swift
@Observable
class LocationManager: NSObject, CLLocationManagerDelegate {
    private let manager = CLLocationManager()

    var currentLocation: CLLocationCoordinate2D?

    override init() {
        super.init()

        manager.delegate = self
        manager.desiredAccuracy = kCLLocationAccuracyBest

        manager.requestWhenInUseAuthorization()
        manager.startUpdatingLocation()
    }

    func locationManager(
        _ manager: CLLocationManager,
        didUpdateLocations locations: [CLLocation]
    ) {
        currentLocation = locations.last?.coordinate
    }
}
```

## このクラスの流れ

```text
LocationManagerが作られる
↓
位置情報の利用許可を求める
↓
現在地の更新を開始する
↓
位置情報が取得される
↓
currentLocationに保存される
```

重要なのはここです。

```swift
var currentLocation: CLLocationCoordinate2D?
```

現在地がまだ取れていない場合もあるため、`?` が付いています。

つまり、

```swift
currentLocation == nil
```

なら、まだ現在地を取得できていない状態です。

# Step 7：Info.plistに位置情報の許可文を追加する

位置情報を使うには、アプリ側で許可理由を設定する必要があります。

Xcodeでプロジェクトを選択し、

```text
TARGETS
↓
PhotoMap
↓
Info
```

を開きます。

次の項目を追加してください。

| Key                                                 | Value                          |
| --------------------------------------------------- | ------------------------------ |
| Privacy - Location When In Use Usage Description    | 写真を記録した場所を地図に表示するために位置情報を使用します |
| Privacy - Photo Library Additions Usage Description | 写真を保存するために写真ライブラリへアクセスします      |

Key名として書く場合は以下です。

```text
NSLocationWhenInUseUsageDescription
NSPhotoLibraryAddUsageDescription
```

位置情報を許可しないと、地図には現在地を出せません。

# Step 10：一覧タブを作る

次に、保存した記録を表示する一覧画面を作ります。

```swift
struct ListTab: View {
    @Environment(\.modelContext) private var modelContext

    @Query(
        sort: \PhotoRecord.createdAt,
        order: .reverse
    )
    private var records: [PhotoRecord]

    var body: some View {
        NavigationStack {
            List {
                ForEach(records) { record in
                    VStack(alignment: .leading) {
                        Text(record.title)
                            .font(.headline)

                        Text(record.createdAt, style: .date)
                            .font(.caption)
                            .foregroundStyle(.secondary)
                    }
                }
            }
            .navigationTitle("記録一覧")
        }
    }
}
```

## `@Query` の意味

```swift
@Query(
    sort: \PhotoRecord.createdAt,
    order: .reverse
)
private var records: [PhotoRecord]
```

これは、

```text
PhotoRecordを全部取得する
作成日時順に並べる
新しい記録を上に表示する
```

という意味です。

前にやったメモアプリと同じ考え方です。

# Step 11：記録追加画面を作る

新しいSwiftファイルを作りましょう。

```text
File
↓
New
↓
File
↓
SwiftUI View
↓
AddRecordView
```

中身を次のようにします。

```swift
import SwiftUI
import SwiftData
import PhotosUI

struct AddRecordView: View {
    @Environment(\.modelContext) private var modelContext
    @Environment(\.dismiss) private var dismiss

    let locationManager: LocationManager

    @State private var title = ""
    @State private var memo = ""

    var body: some View {
        NavigationStack {
            Form {
                Section("情報") {
                    TextField("タイトル", text: $title)

                    TextField(
                        "メモ（任意）",
                        text: $memo,
                        axis: .vertical
                    )
                    .lineLimit(3...6)
                }

                Section("位置情報") {
                    if let location = locationManager.currentLocation {
                        Text("緯度: \(location.latitude)")
                        Text("経度: \(location.longitude)")
                    } else {
                        Text("位置情報を取得中...")
                            .foregroundStyle(.secondary)
                    }
                }
            }
            .navigationTitle("新しい記録")
            .toolbar {
                ToolbarItem(placement: .cancellationAction) {
                    Button("キャンセル") {
                        dismiss()
                    }
                }

                ToolbarItem(placement: .confirmationAction) {
                    Button("保存") {
                        saveRecord()
                    }
                    .disabled(
                        title.isEmpty ||
                        locationManager.currentLocation == nil
                    )
                }
            }
        }
    }

    func saveRecord() {
        guard let location = locationManager.currentLocation else {
            return
        }

        let record = PhotoRecord(
            title: title,
            memo: memo,
            latitude: location.latitude,
            longitude: location.longitude
        )

        modelContext.insert(record)

        dismiss()
    }
}
```

この時点で、写真なしの「タイトル・メモ・現在地」を保存できます。

まずここまで完成させて、保存 → 一覧への反映を確認してください。

# Step 14：写真を選べるようにする

`AddRecordView` にStateを追加します。

```swift
@State private var selectedItem: PhotosPickerItem?
@State private var selectedImageData: Data?
@State private var previewImage: Image?
```

次に、`Form` の先頭へ写真セクションを追加します。

```swift
Section("写真") {
    if let image = previewImage {
        image
            .resizable()
            .aspectRatio(contentMode: .fit)
            .frame(maxHeight: 200)
            .clipShape(
                RoundedRectangle(cornerRadius: 8)
            )
    }

    PhotosPicker(
        selection: $selectedItem,
        matching: .images
    ) {
        Label("写真を選択", systemImage: "photo")
    }
}
```

さらに `NavigationStack` の最後あたりへ追加します。

```swift
.onChange(of: selectedItem) { _, newItem in
    Task {
        if let data = try? await newItem?.loadTransferable(type: Data.self) {
            selectedImageData = data

            if let uiImage = UIImage(data: data) {
                previewImage = Image(uiImage: uiImage)
            }
        }
    }
}
```

これで、写真を選ぶとプレビューが表示されます。

# Step 19：詳細画面を作る

新しいSwiftUI Viewを作ります。

名前は `RecordDetailView.swift` にしてください。

```swift
import SwiftUI
import MapKit

struct RecordDetailView: View {
    let record: PhotoRecord

    var body: some View {
        ScrollView {
            VStack(spacing: 16) {
                if let uiImage = record.uiImage {
                    Image(uiImage: uiImage)
                        .resizable()
                        .aspectRatio(contentMode: .fit)
                        .clipShape(
                            RoundedRectangle(cornerRadius: 12)
                        )
                }

                VStack(alignment: .leading, spacing: 8) {
                    Text(record.title)
                        .font(.title2)
                        .bold()

                    if !record.memo.isEmpty {
                        Text(record.memo)
                            .foregroundStyle(.secondary)
                    }

                    Text(record.createdAt, style: .date)
                        .font(.caption)
                        .foregroundStyle(.tertiary)
                }
                .frame(
                    maxWidth: .infinity,
                    alignment: .leading
                )

                Map {
                    Marker(
                        record.title,
                        coordinate: record.coordinate
                    )
                }
                .frame(height: 200)
                .clipShape(
                    RoundedRectangle(cornerRadius: 12)
                )
            }
            .padding()
        }
    }
}
```

これで、

```text
地図上の写真アイコンを押す
↓
詳細シートが開く
↓
写真・タイトル・メモ・ミニ地図が見える
```

という流れになります。
